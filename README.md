# Hearth

A simple, open-source hosting dashboard built around HestiaCP. Launch WordPress sites and manage your server without the complexity.

## Status

Planning and initial development. There is no working installer or server integration yet.

Hearth will extend HestiaCP rather than fork it. This is an independent project, not an official HestiaCP product.

## Keep it simple

- Four steps to a WordPress site: check server, name website, create login, launch.
- A dashboard with Websites, Backups, Server, and Settings.
- Sensible defaults, with advanced options tucked away.
- Clear progress, useful errors, and resumable setup.
- No required Hearth subscription or cloud account.

## First milestone

Connect a test HestiaCP server, create one WordPress site, verify it works, and open it from the dashboard. Confirm Hestia API capabilities before promising individual integrations.

See [the wizard plan](docs/wizard.md).

## Open source

Hearth is intended to be open source. A license will be selected before code is released. HestiaCP is separately licensed under GPLv3; its attribution and license requirements must be preserved for any reused code.
